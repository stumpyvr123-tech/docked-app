📋 Setup & Installation Manual

Welcome to the official documentation for Docked Widgets (v2.0.0). Follow the system instructions below to install, compile, or audit the standalone application framework.

💻 Installation Procedures

  • macOS (M-Chip Silicon): Download and mount the .dmg file, then drag the application shortcut icon directly into your Mac's Applications directory folder.
  • Windows (64-Bit): Run the targeted NSIS .exe installer setup wizard and follow the automated sequence to launch the tool straight from your desktop environment.
  • ChromeOS / Chromebook: Open the hosted web link in your Chrome browser and click the "Install Application" monitor token icon in the address bar to run borderless as a standalone app drawer window slot.

⚡ Development & Compilation Commands

Execute these terminal command lines inside your project workspace directories to run or package the client files:

Launch the local development sandbox: npm start Compile production Windows installers from your machine: npx electron-builder --win nsis

🔒 Security & Performance Metrics

  • Sandboxed Link Traversal: External web links are automatically caught by the core application controller and securely re-routed to open in your machine's default native web browser.
  • Resource Optimization: Built entirely on lightweight client-side scripts and vanilla formatting to maintain maximum memory efficiency on basic computer hardware configurations.
